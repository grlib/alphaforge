# cases/

失败是一等公民。

| 目录 | 用途 |
|---|---|
| `success/` | 真正帮到判断的案例 |
| `failure/` | Agent 犯错、用户纠正、Skill 失效 |
| `edge-cases/` | 边界与歧义 |

Failure 尽量记录：Context / Expected / Actual / Root Cause / User Correction / Skill / Tool / Prompt / Data / Memory / Reasoning / Evaluation Lesson / Fix / Regression Test

长期目标：Failure Dataset → Evaluation → Better Skills。
