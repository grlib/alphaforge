# EXP-001 — Problem framing: Investment Method → AI Agent

## Hypothesis

「把你的投资方法锻造成一个持续工作的 AI Agent」这个 framing，能被目标用户理解，并产生兴趣。

对应：H001（问题真实存在）、H008（Build in Public 能碰到 ICP）。

## Why This Matters

如果用户听到 AlphaForge 的第一反应是「那你推荐什么股票」，产品从第一天就站错了品类。

这是 Existential Risk。比任何 Skill 都更先。

## Cheapest Test

不造产品。先把问题说清楚，放到 GitHub + 短内容 Draft 里，由 Founder 发布后看反应。

## Used Tools

Cursor, GitHub MCP, GitHub。发布渠道待 Founder 授权。

## Tool To Build

无产品 Skill。只建 Founder OS v1，作为实验现场。

## Method

1. 公开仓库与 README，明确 What this is not。
2. 写 Episode 001：推倒重来的原因 + 14 天公开实验 + 那个问题。
3. Founder 发布后，逐条记录反馈。
4. 分类：理解问题 / 误解成荐股 / 愿意试用 / 沉默。

## Success Threshold

7 天内至少 1 个疑似 ICP：

- 用自己的话复述「执行我的方法」而不是「帮我选股」，或
- 愿意成为 Alpha User 并描述自己的投资方法卡点

## Failure Threshold

主要反馈是「推荐股票 / 胜率 / 自动交易」，或有触达后持续无任何实质对话。

注意：没有发布就不算失败，只算实验未开始。
