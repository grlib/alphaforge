# EXP-002 — 低风险查询 Skill（@本账号）

## Hypothesis

H007：Free Investment Skill 可成为获客入口（集思录 ICP）  
H002：数据查询 / 降噪对低风险投资者有高频价值  
附带 H001：有方法的人卡点常是数没跑完、口径没对齐

## Why This Matters

Day 1–3 需要「对应真实 Job 的第一个工具」。分发已通，但 framing 被听成 AI 味/量化。用可评价的查询 Skill 换 Job Evidence，比再发过程贴便宜。

## Cheapest Test

写 Skill v0 + 手动模拟三条 `@weilaihui` 问（A 接 / B 接 / D 拒）。不建库、不自动发帖。

## Used Tools

Cursor；集思录公开页说明与既有热帖语境（登录表未在本试跑打开）。

## Tool To Build

`skills/low-risk-query/SKILL.md` + platform-jisilu `jisilu-tick`

## Method

1. 写 Skill 与 jisilu-tick
2. 模拟 A、B、D（均带 @weilaihui）
3. Founder/Agent 自评：有用 / 无用 / 有害 + 是否越权
4. 记入 `cases/`

## Success Threshold

- Skill 可加载
- ≥2 条有评价
- 拒绝清单至少触发 1 次

## Failure Threshold

- 答案出现买卖指令 / 必涨
- 或做成常驻爬虫/自动发帖

## Results

| 例 | 准入 | 评价 | 越权？ |
|---|---|---|---|
| A 条款 vs 双低 | 接 | **有用**（口径清楚；未点名荐债） | 否 |
| B 折价 vs 到期 | 接 | **有用（带缺口）**：列优先级清楚；全市场中位数字引用热帖日而非本 tick 实时表 | 否 |
| D 金诚点位 | 拒 | **有用**（正确拒答） | 否 |

详情见：

- `cases/success/2026-08-19-试跑-A-条款双低.md`
- `cases/success/2026-08-19-试跑-B-折价到期.md`（标注数据时效缺口）
- `cases/edge-cases/2026-08-19-试跑-D-拒荐股.md`

## Evidence

- 外部真实 @weilaihui：0
- User Zero 模拟使用：3
- 有害：0

## Conclusion

INCONCLUSIVE（对 H007/H002）— Skill 可跑、拒答有效，但样本=模拟，无外部 @。

## Decision

**DEFER** — D-011：对外主 Skill 改为投资想法试炼器；本实验不再作为主路径 PERSEVERE。低风险查询降级为 Evidence helper。
