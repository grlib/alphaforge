# research/

公开市场、竞品、替代方案、用户访谈。不要让 Research 只存在于聊天窗口。

每份研究必须区分：

`Fact` / `Evidence` / `Interpretation` / `Hypothesis`

| 目录 | 用途 |
|---|---|
| `market/` | 市场与品类 |
| `competitors/` | 竞品 |
| `alternatives/` | 用户现在用什么替代（包括「什么都不做」） |
| `interviews/` | 对话与观察，尽量记原话。入库前脱敏：评论者匿名；不写关注时间 / 私信对象 / 私信原文 |

需要外部事实时：Search first。
