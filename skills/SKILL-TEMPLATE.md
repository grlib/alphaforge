# Investment Skill Template

在证明某个 Skill 值得存在之前，不要预先填写假数据。先写 Purpose 与 Hypothesis。

```text
├── Tools
├── Data Sources
├── Rules
├── Memory
├── Evidence
├── Failure Modes
├── Evaluation
├── Cases
└── Version History
```
