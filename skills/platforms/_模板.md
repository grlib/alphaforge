文案不在此维护：简介 / 主钩子只引用 `内容/品牌/身份统一包.md`。

## Posting

- 发帖入口 URL
- 草稿路径：`内容/草稿/...`
- 发布后：立刻把公开 URL 写入 `增长.md` 与当日 `每日/`
- 正文软链：简介层 `github.com/grlib`；正文再放 `github.com/grlib/alphaforge`

## WebBridge ops

1. 遵守 `.cursor/rules/kimi-webbridge.mdc`
2. session 命名：`alphaforge-<platform>-<task>`（一任务一 session）
3. 少开标签；能复用 tab 就不要 `newTab`
4. **任务结束必须 `close_session`**
5. 登录 / 验证码 / 昵称冷却 → 交 Founder；其余 Agent 做
