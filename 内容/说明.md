# content/

Build in Public 内容。中文为主 + English key terms。不要机械双语。

| 目录 / 文件 | 用途 |
|---|---|
| `ideas/` | 未写的题目 |
| `草稿/` | 待 Founder 授权发布（按期 × 按站） |
| `品牌/` | 身份统一包、头像 |
| `内容模板.md` | Canonical 五段 + 各站裁切规格 |
| `说明.md` | 本文件 |

不要自动发布外部平台，除非 Founder 明确授权且环境已有对应 Tool。

---

## 每日发布流程

1. **先写 Canonical**（GitHub 五段 Build Log）。事实只维护这一份。对外**不写「明天做什么」**；不写「不是荐股」「N 天」。
2. **再按站裁切**：对照 `内容模板.md` 各站规格改标题句式、字数、图位、入口（知乎导入 / 雪球长文 / X thread 等）。
3. **发布门禁**：各站 Skill 里写的字数 / 形态条件不满足，不准点发布。
4. **发完立刻核公开页**（不要只看编辑器）：全文是否在、关键节 / 判断是否在、链接是否可点。截断则撤回重来，并记进该站 Skill 的 pitfalls。
5. URL 回写 `增长.md` 与当日 `每日/`；WebBridge 用完 `close_session`。

详见：`内容/内容模板.md`、`技能/平台/*/SKILL.md`。
