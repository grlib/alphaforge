# Day 2：用真实浏览器登录态，把五个平台收成 Skill

## 总结昨日

昨天把 GitHub、雪球、知乎、X 的入口打通，并发了第一篇：为什么把旧的 AI 股票系统推倒重来。当时各站简介还不统一，改资料、发帖是一次性手工。

## 今天做什么

把「我是谁」收成一份身份统一包，再给每个已开通平台做成独立 Skill。先覆盖改基础信息（显示名、简介、网站、头像路径）和发文。回复、私信留空壳，等有真实互动再做——这是在为后续各平台 Agent 做准备。集思录按同一套新加入流程开通。

## 使用什么工具

Kimi WebBridge：用本机真实浏览器登录态改资料、发帖、核对每个站的坑，用完关闭。Cursor 把身份包和 Skill 写进仓库。GitHub MCP 更新公开入口。

## 今天造什么工具

- 身份统一包：国内中文 / 国外英文，文案只此一处
- 五站 Platform Skill：GitHub / X / 雪球 / 知乎 / 集思录（改资料 + 发文）
- 新加入流程：授权 → 写 Skill → 同步基础信息 → 再问是否同步已有文章
- 集思录昵称不改（改名耗金币、会降权新人）

这些是分发侧工具，不是投资 Skill。

## 得到什么结果 + 对外发布

已落地：5 个 Skill 可按站加载；集思录已开通并同步了上一篇；GitHub / X 资料已按身份包同步；知乎简介已同步。

还没过的墙：头像自动化 Chrome Not allowed，五站仍待人工；集思录普通用户不能改签名/头像；知乎改名规则卡住目标显示名；雪球站点间歇打不开，简介同步未完成。
