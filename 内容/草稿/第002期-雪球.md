# 五个平台收成 Skill 之后，发帖链路先把正文弄丢了

公开第二天，我没有先造投资 Skill，而是把「改资料 + 发文」收成可复用的 Platform Skill。五个站的入口通了；知乎这篇却一度只剩结尾一句提问——屏幕有字，入库几乎没有。

**数字：**

1. **5** 个 Platform Skill 进了仓库（GitHub / X / 雪球 / 知乎 / 集思录）
2. **1** 个身份统一包：国内中文、国外英文，文案只此一处
3. 失败墙仍在：**头像自动化 Not allowed**、集思录普通用户不能改签名/头像、知乎改名规则卡住、雪球曾间歇打不开、知乎 Draft.js 保存态 ≠ 屏幕文字

用的是本机真实浏览器登录态（Kimi WebBridge），用完关掉，不新造浏览器运行时。
