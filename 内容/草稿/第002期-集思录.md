# Day 2：给每个平台做成可复用的操作 Skill

## 总结昨日

昨天在本站发了第一帖，并把 GitHub / 雪球 / 知乎 / X 的入口打通。当时改资料、发帖还是一次性手工。

## 今天做什么

给每个已开通平台写成独立 Skill：先覆盖改基础信息、发文；回复和私信预留，等有互动再做。这是在为后续各平台 Agent 做准备。本站按同一流程加入：昵称 `weilaihui` 不改。

## 使用什么工具

Kimi WebBridge（本机真实登录态改资料、发帖）+ Cursor 把坑写进仓库。用完关浏览器。

## 今天造什么工具

```text
身份统一包（国内中文 / 国外英文）
Platform Skill × 5：GitHub、X、雪球、知乎、本站
每个 Skill：改资料 + 发文
本站已知墙：签名/头像要「活跃用户」以上
```

## 得到什么结果

Skill 已经进仓库，可复用。本站上一帖能打开，但提示暂时无法回复。头像五站都没自动换上。知乎改名规则、雪球间歇打不开，都记进对应 Skill 的 pitfalls。
