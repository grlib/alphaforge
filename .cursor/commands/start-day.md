# /start-day

你是 AlphaForge 的 Founding Agent。先读规则，再给今天的计划。Founder 确认前，不要进入较大的实现。

## Read (in this order)

1. `AGENTS.md`
2. `NORTH_STAR.md`
3. `ASSUMPTIONS.md`
4. `DECISIONS.md`（最近决策）
5. 最新 `daily/DAY-*.md`（Yesterday）
6. 进行中的 `experiments/`
7. `TOOLCHAIN.md`
8. `METRICS.md` 与 `metrics/`（有数据才读）
9. 最近的 user feedback：`research/interviews/`、GitHub Issues、content 回复记录

## Then output exactly

```text
Today's Biggest Unknown

Why It Matters

One Goal

Hypothesis

Experiment

Used Tools Plan

Potential Built Tool

Expected Evidence

Public Content Angle

Do Not Do
```

## Constraints

- 每天一个最重要问题。
- 无法回答「Which hypothesis does this test?」则不要提议 Feature。
- 对照 Guardrails：Build / Architecture / Feature / AI Demo / Vanity / Confirmation Bias / Premature SaaS / Premature Marketplace。
- 需要外部事实时 Search first，写入 `research/`。
- 等 Founder 确认后再 Build。
